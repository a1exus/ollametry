# CLAUDE.md

## Project overview

ollametry is a Go reverse proxy in front of a host-installed Ollama (macOS app, not Docker). It relays every request unchanged and records OpenTelemetry metrics from the usage stats inside Ollama's responses, plus gauges from polling `/api/ps` and `/api/tags`. It exports OTLP/HTTP to `otel-lgtm` from `~/opt/grafana` by joining that stack's `grafana_default` network. Module: `github.com/a1exus/ollametry`.

## Layout

| Path | Role |
|---|---|
| `cmd/ollametry` | Wiring, graceful shutdown, `healthcheck` subcommand (distroless has no curl) |
| `internal/config` | Flags with `OLLAMETRY_*` env defaults; all errors reported at once |
| `internal/route` | Path → `http.route` template, GenAI operation, response dialect. Unknown paths get no route (cardinality) |
| `internal/dialect` | `Framer` (JSON / NDJSON / SSE, chunk-boundary safe, size-capped) and one `Decoder` per API family filling a `Result` |
| `internal/proxy` | `httputil.ReverseProxy` + body tap; `exchange.errorType` classifies outcomes; `finish` records everything |
| `internal/ollama` | `/api/*` client and `Poller`; gauges are observable and read the last snapshot (no I/O in callbacks) |
| `internal/telemetry` | Meter provider via `autoexport` (honors `OTEL_*`), instruments, HTTP duration bucket view |
| `internal/genai` | GenAI semconv names and buckets (not generated by the Go SDK: Development status upstream) |
| `deploy/grafana/ollametry.json` | Dashboard, uid `ollametry`, datasource variable defaulting to uid `prometheus`; provisioned by `~/opt/grafana` (`make dashboards`) |

## Request flow

1. `ServeHTTP` matches the route. For inference routes it buffers the body up to `MaxInspectBytes` to read `model` (larger bodies: prefix + rest via `MultiReader`, model from a token walk of the prefix).
2. `rewrite` sets the upstream URL and `X-Forwarded-*`, and drops `Accept-Encoding` on inference routes so the transport negotiates and transparently decodes gzip.
3. `modifyResponse` picks the `Format` from `Content-Type` and wraps the body in `tapBody`, which feeds the `Framer` → `Decoder` as bytes are relayed. `FlushInterval: -1` flushes every write.
4. After `ReverseProxy.ServeHTTP` returns (or panics with `http.ErrAbortHandler`, recovered and re-raised), `finish` records metrics with `context.WithoutCancel`.

## Verified facts and gotchas

Verified against Ollama 0.40.13 and `grafana/otel-lgtm:0.39.0` (Prometheus 3.15.1, Grafana 13.3.0).

- **Reasoning comes first**: native `thinking`, OpenAI `reasoning`, Anthropic `thinking_delta`, Responses `reasoning_summary_text.delta`. Time to first token counts them.
- **Cached tokens**: native and OpenAI report input including cached (`prompt_eval_count` 21, cached 20); Anthropic reports them apart (`input_tokens` 1 + `cache_read_input_tokens` 20). `Result.InputTokens` always includes cached.
- **Anthropic `message_start` usage is provisional** (6 input tokens); the final `message_delta` holds the real counts. Usage fields are pointers so partial updates work.
- **`/v1/completions` streams repeat a zeroed `usage`** on every chunk; only non-zero usage is taken.
- **OpenAI streams have no usage** unless the client sends `stream_options.include_usage`; when they do, the final chunk also has llama.cpp `timings` (`predicted_ms`), used for time per output token.
- **Ollama's `Host` check accepts `host.docker.internal`**; `SetURL` sends the upstream host. Docker Desktop routes `host.docker.internal` to the host loopback, where Ollama listens.
- **OTLP → Prometheus names**: `.` → `_`, unit suffixes added (`_seconds`, `_bytes`), counters get `_total`, `{token}`-style units add nothing. A unit of `"1"` adds `_ratio`, which is why `ollama.up` has no unit.
- **OTLP counters have no start point in Prometheus**: the first export of a series is its baseline, so a model's first request is missing from `rate()`/`increase()`.
- **Series from a replaced container linger 5 minutes** (no staleness markers for OTLP) with a different `service_version`; dashboard queries aggregate by model name, never `count()` raw series.
- **httpconv appends its default options after the caller's**, so bucket overrides must be SDK Views (`telemetry.httpDurationView`).
- **The dashboard is file-provisioned by `~/opt/grafana`** (`make dashboards` there copies `deploy/grafana/*.json`). Grafana refuses UI and API saves of provisioned dashboards, so edit the JSON here and re-sync.
- **`govulncheck` below v1.9 panics on Go 1.27** (`unexpected expr: *ast.KeyValueExpr`).
- **Ollama decodes requests with `encoding/json`**: keys match case-insensitively (`"Model"` works) and the last duplicate wins. `modelFromPrefix` (bodies over `MaxInspectBytes`) mirrors this; `FuzzModelFromPrefix` checks it against `encoding/json` on every valid body.

## Common commands

```sh
make check              # lint + test + vuln (containers)
make up && make health  # build, run, verify against the real Ollama
make smoke MODEL=granite4.2:8b
make fuzz FUZZTIME=2m      # fuzz framer, decoders, model extraction
make -C ~/opt/grafana dashboards   # provision the dashboard
```

Inspect exported series without Grafana credentials:

```sh
docker exec otel-lgtm curl -s -G localhost:9090/api/v1/query --data-urlencode 'query=ollama_up'
```
